# PAINT YOUR LOGO WALL — Logo Crew

Baseline repository for reconstruction of the Logo Crew interactive wall experience.

## Status

- `main` is the clean baseline only.
- Product development must happen on isolated version branches.
- No feature implementation belongs directly on `main` without explicit Product Owner approval.

## Reconstruction source

The canonical visual reference is the supplied `LOGO CREW.mp4` review material.

## Initial target

Reconstruct the Painter experience first as an isolated V1, preserving a modular architecture for later Electrician, image mural, spray and other crew/method variants.
